# Miami Machine Learning GitHub Repository
---
Welcome to the Miami Machine Learning Meetup - a group dedicated to all things machine learning and artificial intelligence. Whether you are a beginner looking to learn the basics or a seasoned professional interested in the latest advancements, this is the place for you. Let's come together to exchange ideas, share knowledge, and collaborate on projects. Join us for presentations, workshops, networking events, and more. 

This repository serves as the data base for all event code, datasets, and notebooks for Miami Machine Learning meetups.
